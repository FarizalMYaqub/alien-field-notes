One original line of plain text: a review of planet Earth left by an alien tourist, written by a small program that prints it to `/output/entry.txt`. The line weighs the alien's outside view first — the visitor came for the oceans and stayed for the glowing rectangles the locals worship instead of them — and lands its verdict and punch at the end: four stars, and the Wi-Fi up here is terrible.

## Run it

```sh
node main.ts
```
